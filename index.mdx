ThrottlingTroll is a production-ready rate limiting and circuit-breaking library for .NET. Add ingress throttling to protect your APIs from overload, apply egress throttling to respect third-party rate limits, and implement circuit-breaking to prevent cascading failures — all with a single NuGet package.

## What ThrottlingTroll does

**Ingress throttling** automatically returns `429 TooManyRequests` when a client exceeds configured limits. It works as an ASP.NET Core Middleware or Azure Functions Middleware, with zero changes to your endpoint logic.

**Egress throttling** wraps `HttpClient` so outbound calls are throttled before they leave your service. When a limit is hit, the handler returns `429` locally — no actual network call is made.

**Circuit breaking** tracks failure rates and temporarily blocks traffic when an endpoint is unhealthy, allowing recovery via a configurable trial interval.

## Minimal example

```csharp Program.cs
using ThrottlingTroll;

var builder = WebApplication.CreateBuilder(args);
var app = builder.Build();

app.MapGet("/", () => "Hello ThrottlingTroll!");

// Limit to 10 requests per 10 seconds
app.UseThrottlingTroll(options =>
{
    options.Config = new ThrottlingTrollConfig
    {
        Rules =
        [
            new ThrottlingTrollRule
            {
                LimitMethod = new FixedWindowRateLimitMethod
                {
                    PermitLimit = 10,
                    IntervalInSeconds = 10
                }
            }
        ]
    };
});

app.Run();
```
